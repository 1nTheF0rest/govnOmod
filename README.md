# ГОВНОМОД

Добро пожаловать в самое бесполезное, сомнительное и необъяснимо необходимое программное обеспечение, когда-либо помещённое человеком в Minecraft.

## ЧТО ЭТО ЗА ГОВНО?

Говномод — это мод, созданный человеком, который однажды посмотрел на Minecraft и решил:

> «Этой игре явно не хватает ещё немного говна».

Так появился Говномод.

Он не улучшает Minecraft.
Он не делает Minecraft красивее.
Он не делает Minecraft удобнее.

Он просто **существует**.

И этого уже достаточно, чтобы задать человечеству несколько неприятных вопросов.

## СКОЛЬКО ГОВНА ДОБАВЛЯЕТ МОД?

**Базовый уровень говна: 100%.**

После установки:

- Minecraft получает дополнительный слой говна.
- Настройки получают дополнительный слой говна.
- Клавиши получают дополнительный слой говна.
- Конфигурация получает дополнительный слой говна.
- Разработчик получает дополнительный слой говна.
- Пользователь получает возможность всё это отключить.
- Но зачем-то всё равно продолжает пользоваться.

### Расчёт говна

**1 установка = 37 условных единиц говна.**

**1 запуск Minecraft = +12 единиц.**

**1 открытие меню Говномода = +8 единиц.**

**1 изменение настройки = +3 единицы.**

**1 попытка понять, зачем этот мод вообще существует = +50 единиц.**

Формула количества говна:

**Г = У × 37 + З × 12 + М × 8 + Н × 3 + В × 50**

Где:

- **Г** — количество говна;
- **У** — установки;
- **З** — запуски;
- **М** — открытия меню;
- **Н** — изменения настроек;
- **В** — попытки понять происходящее.

## ЗОНЫ ГОВНА

### Зона 0: «Ещё нормально»
**0–25 говна**

Minecraft ещё выглядит как Minecraft.

### Зона 1: «Что это?»
**26–100 говна**

Пользователь начинает замечать странности. Появляются вопросы. Ответов нет.

### Зона 2: «Зачем я это установил?»
**101–500 говна**

Мод уже уверенно занимает место в `.minecraft`. Удалять его поздно. Психологически.

### Зона 3: «ГОВНО»
**501–1000 говна**

Minecraft продолжает работать, но смысл происходящего окончательно потерян.

### Зона 4: «Разработчик явно что-то натворил»
**1001–5000 говна**

Начинается настоящий промышленный выпуск говна.

Конфиги существуют.
Клавиши существуют.
Меню существует.

Причина их существования отсутствует.

### Зона 5: «Фуня»
**5001+ говна**

Вы достигли максимального уровня.

Дальше измерять количество говна невозможно, потому что измерительный прибор сам стал говном.

## ВОЗМОЖНОСТИ МОДА

- Настраиваемый keybind для включения и выключения мода.
- Отдельный keybind для открытия меню.
- Бинды можно переназначить в **Настройки → Управление → Назначение клавиш**.
- Настройка CPS по умолчанию и отдельные значения для блоков через `config/govnomod.json`.
- Состояние мода сохраняется между запусками.
- Никакой практической пользы.

**после установки в вашем Minecraft станет больше говна.**

Именно это и было целью.
