# Говномод

Самый бессмысленно необходимый мод, который когда-либо попадал в твой `.minecraft`.

Добавляет функции, которые никто не просил, настройки, которые никто не понимает, и клавиши, которые обязательно будут нажаты в самый неподходящий момент.

## Возможности

- Настраиваемый keybind для включения и выключения мода.
- Отдельный keybind для открытия меню.
- Бинды можно переназначить прямо в **Настройки → Управление → Назначение клавиш**.
- Настройка CPS по умолчанию и отдельные значения для блоков через `config/govnomod.json`.
- Состояние мода сохраняется между запусками.
- Никакой практической пользы. Именно поэтому мод существует.
