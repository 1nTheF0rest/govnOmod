# govnOmod

Клиентский Fabric-мод для Minecraft 1.21.11, сделанный по механике Fast Block Placement.

## Управление

- **V** — включить/выключить ускоренную установку блоков.
- **O** — открыть меню настроек.
- В меню можно выбрать задержку установки от **0 до 20 тиков**.
- Настройки сохраняются в `config/govnomod.json`.

Клавиши зарегистрированы через стандартную систему Minecraft, поэтому их можно переназначить в **Настройки → Управление → Назначение клавиш**.
